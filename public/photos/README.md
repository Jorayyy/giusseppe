# Add Giuseppe's real photos here

1. Save your photos as `1.jpg`, `2.jpg`, `3.jpg`, etc. in this folder
2. Then update `src/app/page.tsx` PHOTOS array to:
```
const PHOTOS = [
  "/photos/1.jpg",
  "/photos/2.jpg",
  "/photos/3.jpg",
  "/photos/4.jpg",
  "/photos/5.jpg",
  "/photos/6.jpg",
];
```
Or just replace the Unsplash URLs with your own image URLs.
